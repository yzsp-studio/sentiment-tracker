## 🇨🇳 中文

面向网页端与电脑端的舆情监控、调研、社交媒体反馈收集与品牌声量追踪技能。采用「全面检索 + 深度挖掘」双层策略：先做全网检索把握整体态势，再对微博、知乎、即刻、脉脉、B站、抖音等重点平台逐站深度检索并用浏览器实查，完成内容筛选与原始帖子溯源。硬性要求每条舆情都携带可直接访问的原帖链接和原始标题，优先一手信源（用户原始帖 > 媒体报道 > 二手转述），只有在穷尽方法确实找不到原帖时才用二手信源并说明原因，最终以文档交付。即使用户只指定了某几个平台，也必须补齐其它核心平台——指定平台只是「重点关注」而非「只看这个」。

### ✨ 能做什么

- 全网检索 + 重点平台深度检索的五步舆情工作流，指定平台之外仍补齐其它核心平台
- 每条舆情附可直接访问的原帖链接与原始标题，缺链接即整份报告不合格，宁少不凑
- 一手信源优先：原始帖 > 媒体报道 > 二手转述；用二手必须写明为什么找不到原帖
- 需要登录时拉起浏览器控制交由用户完成登录，而不是换平台、关弹窗或轻易放弃
- 覆盖微博、知乎、即刻、脉脉、B站、抖音等多平台的搜索、筛选与溯源
- 以文档交付结果并附全部一手信源链接，除非用户明确指定其它格式

## 🇬🇧 English

A public-opinion monitoring, research and brand-sentiment tracking skill for web and desktop sessions. It runs a two-layer strategy — broad web-wide search first, then deep per-platform digging with real browser checks on major social platforms (Weibo, Zhihu, Jike, Maimai, Bilibili, Douyin and more) — covering content filtering and tracing back to original posts. Every item is required to carry a directly openable link to the original post plus its original title; primary sources outrank media coverage and second-hand retellings, and secondary sources are allowed only after every route to the original has been exhausted and with a stated reason. Results are delivered as a document. Even when the user names only a few platforms, the other core platforms must still be covered: named platforms are a focus, not the whole scope.

### ✨ What it does

- Five-step workflow of web-wide search plus deep per-platform digging, filling in the other core platforms beyond the ones the user names
- Every item carries an openable original-post link and original title; one missing link fails the whole report — fewer items beats padding
- Primary sources first (original post > media coverage > retelling); secondary sources require a written reason why the original could not be found
- When login is needed, browser control is handed to the user to complete sign-in rather than switching platforms, closing the prompt or giving up
- Covers search, filtering and source tracing across Weibo, Zhihu, Jike, Maimai, Bilibili and Douyin
- Delivers results as a document with all primary-source links, unless the user explicitly asks for another format
